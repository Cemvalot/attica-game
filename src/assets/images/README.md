# Game images

## Παιχνίδι 1 — Σύνδεσε τον SDG

`sdg1.jpg` … `sdg17.jpg` — μία εικόνα ανά SDG για τις δράσεις.

## Παιχνίδι 2 — Ποιος SDG ταιριάζει

`sdg1-2.jpg` … `sdg17-2.jpg` — **ξεχωριστές** εικόνες από το παιχνίδι 1.

Παράδειγτα για τις 3 σκηνές (ένα αρχείο ανά επίπεδο):

| Αρχείο | Επίπεδο | Caption | SDG (όλοι σωστοί) |
|--------|---------|---------|-------------------|
| `sdg13-2.jpg` | 1 | Ένα πιο πράσινο σχολείο | 7, 11, 13 |
| `sdg2-2.jpg` | 2 | Υγιεινό φαγητό για όλους | 2, 3, 10 |
| `sdg10-2.jpg` | 3 | Όλοι μαζί μπορούμε | 5, 10, 16 |

Το `imageSdgId` στο `games.js` καθορίζει ποιο αρχείο φορτώνεται (π.χ. `13` → `sdg13-2.jpg`).

## Menu & Eco Speed

- Menu: `menu-connect.jpg`, `menu-match.jpg`, `menu-eco-speed.jpg`
- Eco Speed: `eco-*.jpg` (βλ. `imageMap.js`)

Μπορείς `.png` / `.webp` — άλλαξε την επέκταση στο `imageMap.js`.

## Ταχύτητα

Οι εικόνες πρέπει να είναι **κάτω από ~500KB** η καθεμία (ιδανικά 100–300KB) για kiosk. Αν η εφαρμογή αργεί:

```bash
npm run compress:images
```

Μετά κάνε commit τις συμπιεσμένες εικόνες. Μην ανεβάζεις αρχεία 5–30MB.
